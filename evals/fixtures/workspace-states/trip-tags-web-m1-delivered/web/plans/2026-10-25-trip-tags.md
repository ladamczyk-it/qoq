## Milestone 2: Tag editing and filtering, live

**Size:** S
**Goal:** Users add and remove a trip's tags from the list and filter it by one, through the live API.
**Depends on:** api:Milestone 1
**Contracts:** as Milestone 1.
**Scenarios:**

- **Given** a trip with no tags **When** the user adds "Beach" **Then** the trip shows `beach`, as the server returned it
- **Given** tagged trips **When** the user picks `beach` **Then** only the trips the server returns for `beach` are listed

## Milestone 3: E2E delivery

**Size:** M
**Goal:** The manifest's three scenarios pass end to end against a running api.
**Depends on:** api:Milestone 2
**Contracts:** as Milestone 1.
**Scenarios:** the manifest's, verbatim:

- **Given** a trip with no tags **When** the user adds "Beach" and "family" to it **Then** the trip shows the tags `beach` and `family`
- **Given** tagged trips **When** the user picks the tag `beach` **Then** only trips tagged `beach` are listed, and clearing the filter lists every trip again
- **Given** the user tagged a trip on one device **When** they open the trip list on another **Then** the same tags are there
