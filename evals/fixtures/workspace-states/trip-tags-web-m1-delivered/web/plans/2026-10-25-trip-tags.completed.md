## Milestone 1: Tags in the trip list, against the contract's shape — delivered 2026-10-25

**Size:** S
**Goal:** The client speaks the tag contract and the list renders tags and a tag filter, proven against a typed fake.
**Depends on:** none
**Contracts:** the manifest's, copied:

```ts
interface ITrip {
  id: string;
  name: string;
  startsOn: string;
  tags: string[];
}
// PUT /trips/:id/tags { tags: string[] } → 200 ITrip | 400 { error } | 404 { error }
// GET /trips?tag=<tag> → 200 ITrip[]
```

**Scenarios:**

- **Given** trips with tags **When** the list renders **Then** each trip shows its tags
- **Given** a selected tag **When** the list renders **Then** only trips with that tag are shown

**Context:** `src/api/trips.ts` hand-mirrors api's `ITrip` and exports `fetchTrips()` over `fetch` against `BASE`. Add `tags: string[]` to `ITrip`, an optional `tag?: string` to `fetchTrips` (sent as `?tag=`, URL-encoded, omitted when empty), and `setTripTags(id, tags): Promise<ITrip>` doing `PUT /trips/:id/tags`. - [ ] A 404 from `setTripTags` rejects with an `Error` whose message contains `404`

- **Agent tier:** `sonnet`

- **Files:**

**Context:** `TripList` fetches in a `useEffect` and renders a `<ul>`.
