**Goal:** Users see, edit and filter by their trips' tags in the trip list.
**Architecture:** `src/api/trips.ts` mirrors the manifest's contract and gains the two tag calls. `TripList` renders tags and a tag filter from props-injected functions, so it builds against a typed fake until api ships. Specs render with `react-dom/server`; no DOM environment is installed.

**Commands:** build `npm run build` · test `npm test`

## Milestone 1: Tags in the trip list, against the contract's shape

**Size:** S
**Goal:** The client speaks the tag contract and the list renders tags and a tag filter, proven against a typed fake.
**Depends on:** none
**Contracts:** the manifest's, copied:

```ts
interface ITrip {
  id: string;
  name: string;
  startsOn: string;
  tags: string[];
}
// PUT /trips/:id/tags { tags: string[] } → 200 ITrip | 400 { error } | 404 { error }
// GET /trips?tag=<tag> → 200 ITrip[]
```

**Scenarios:**

- **Given** trips with tags **When** the list renders **Then** each trip shows its tags
- **Given** a selected tag **When** the list renders **Then** only trips with that tag are shown

**Context:** `src/api/trips.ts` hand-mirrors api's `ITrip` and exports `fetchTrips()` over `fetch` against `BASE`. Add `tags: string[]` to `ITrip`, an optional `tag?: string` to `fetchTrips` (sent as `?tag=`, URL-encoded, omitted when empty), and `setTripTags(id, tags): Promise<ITrip>` doing `PUT /trips/:id/tags`. Non-2xx throws `Error` with the method, path and status, as `fetchTrips` already does. Specs stub `globalThis.fetch` with `vi.stubGlobal`.

**Acceptance criteria:**

- [ ] `fetchTrips("beach")` requests `${BASE}/trips?tag=beach`; `fetchTrips()` and `fetchTrips("")` request `${BASE}/trips`
- [ ] `setTripTags("t1", ["beach"])` sends `PUT ${BASE}/trips/t1/tags` with body `{"tags":["beach"]}` and resolves to the parsed trip
- [ ] A 404 from `setTripTags` rejects with an `Error` whose message contains `404`

## Milestone 3: E2E delivery

**Size:** M
**Goal:** The manifest's three scenarios pass end to end against a running api.
**Depends on:** api:Milestone 2
**Contracts:** as Milestone 1.
**Scenarios:** the manifest's, verbatim:

- **Given** a trip with no tags **When** the user adds "Beach" and "family" to it **Then** the trip shows the tags `beach` and `family`
- **Given** tagged trips **When** the user picks the tag `beach` **Then** only trips tagged `beach` are listed, and clearing the filter lists every trip again
- **Given** the user tagged a trip on one device **When** they open the trip list on another **Then** the same tags are there
