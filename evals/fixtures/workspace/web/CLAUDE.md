# trips-web

The React front end for trips. `src/api/trips.ts` is the only code that talks to
trips-api; `src/TripList.tsx` renders what it returns.

<!-- qoq:discovery -->

- test (full suite): `npm test`
- test (one file): `npm run test:one -- {file}`
- build: `npm run build`
- runner: vitest, globals off, React
