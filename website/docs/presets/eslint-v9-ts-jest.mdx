# TypeScript + Jest

The **`@ladamczyk/qoq-eslint-v9-ts-jest`** preset — an opinionated [flat-config](https://eslint.org/docs/latest/use/configure/configuration-files) bundle with every plugin and rule tuned for **TypeScript + Jest** projects.

```bash
npm install -D @ladamczyk/qoq-eslint-v9-ts-jest
```

Extend the preset's flat-config array with `defineConfig` and scope it with your own `files`:

```js
import { configs } from '@ladamczyk/qoq-eslint-v9-ts-jest';
import { defineConfig } from 'eslint/config';

export default defineConfig({
  files: ['src/**/*.{ts,tsx}'],
  extends: [configs.base],
});
```
