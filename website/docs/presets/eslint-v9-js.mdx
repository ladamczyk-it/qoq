# JavaScript

The **`@ladamczyk/qoq-eslint-v9-js`** preset — an opinionated [flat-config](https://eslint.org/docs/latest/use/configure/configuration-files) bundle with every plugin and rule tuned for **JavaScript** projects.

```bash
npm install -D @ladamczyk/qoq-eslint-v9-js
```

Extend the preset's flat-config array with `defineConfig` and scope it with your own `files`:

```js
import { configs } from '@ladamczyk/qoq-eslint-v9-js';
import { defineConfig } from 'eslint/config';

export default defineConfig({
  files: ['src/**/*.{js,jsx}'],
  extends: [configs.base],
});
```
